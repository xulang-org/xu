# 一、 品牌核心哲学与基因

### 1.1 品牌命名与标准字标规范
- 官方品牌法定英文字标恒定为全大写 **`XU`**（禁止写作 `Xu` 或 `xu`，除非在 CLI 命令行程序命令 `$ xu build` 中使用小写二进制名）。
- 子品牌族谱标准字标统一采用全大写组合：**`XUFLOW`**、**`XUPKG`**、**`XUDOCS`**、**`XUUI`**。

### 1.2 品牌三大技术支柱
1. **ROCK-SOLID (坚若磐石)**：所有权与仿射类型系统，编译期排除一切数据竞争与内存泄漏。
2. **ZERO GC (零运行时垃圾回收)**：确定性生命周期管理，零毫秒级 GC 暂停时间。
3. **SUPERSONIC (超音速编译与原生执行)**：高阶并行编译器与直接机器码生成。

# 二、 基础识别系统：标志与几何网格

### 2.1 甲骨金石母图腾 (Oracle Totem Master Geometry)
- **几何构成**：外层坚固平底 U 型容器（底宽 $320\text{px}$，高 $230\text{px}$）+ 内部对称向心折线骨架 `><`。
- **中心归一化坐标**：图腾质心严格锁定在 $(250, 255)$。在任何媒介中置入时，必须通过 `transform="translate(CX, CY) scale(S)"` 并叠加 `translate(-250, -255)` 实现**双轴绝对居中**。

# 五、 语法高亮与 XU 语言专有符号规范

### 5.1 库与模块导入声明：`#` 专属语法色阶 (Module Import vs Comments)
- **`#` 属于导入库/模块指令**（如 `#net/http`、`#ui/draw`、`#std/sync`），**严禁将其渲染为灰色注释（Comments）**！
- **导入专色规范**：
  - 前缀 `#`：加粗醒目朱砂红 (`#FF385C` / `#BE123C`)；
  - 模块路径：冰魄天蓝 / 深洋海蓝 (`#38BDF8` / `#0284C7`)，字重 700；
  - 注释行：仅限双斜杠 `//` 引导的文本，使用中灰斜体 (`#64748B` / `#78716C`)。

### 5.2 XU 语言全量语法高亮双模光学对照矩阵 (10 大核心语法 Token)

| 语法 Token 分类 | 语法示例 | 暗黑模式 (Dark `#050508`) | 明亮模式 (Light `#F8F9FA`) | 印刷专色 / WCAG 对比度 |
